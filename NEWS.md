# PVomega 0.0.0.9000

## New features

* Added `omega_from_counts()` for calculating the Omega measure from
  observed and expected counts.

* Added `omega_from_table()` for calculating Omega from a contingency
  table.

## Documentation

* Added documentation and examples for the main Omega functions.

* Added a vignette demonstrating the calculation and interpretation of
  Omega.

* Added a "Caveats and Considerations" article describing important
  considerations when applying and interpreting Omega, including limitations
  related to spontaneous reporting data, sparse data, analysis choices, and
  statistical interaction signals.

* Added references to the original methodological work on Omega and related
  applications in pharmacovigilance.

* Expanded the README with an introduction to the package, usage examples,
  methodological background, and references.

* Added a pkgdown website for browsing package documentation, function
  reference material, articles, and release notes.

## Testing and quality assurance

* Added automated tests for the core Omega calculations.

* Added automated R package checks to support package quality assurance and
  CRAN compatibility.

* Added test coverage infrastructure.

## Development infrastructure

* Added GitHub Actions workflows for automated package checks and
  documentation-related tasks.

* Added pkgdown configuration for automated website generation.

* Added package status and development badges to the README.

* Added package metadata and configuration in preparation for CRAN
  submission.
